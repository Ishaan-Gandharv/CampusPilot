# CampusPilot — Student Assignment Manager

CampusPilot is a beginner-friendly Python application that helps students manage their assignments from the terminal.

## Features

- Add assignments with due dates and priorities
- View all saved assignments
- Mark assignments as completed
- Delete assignments
- Save assignment data using JSON file handling
- Validate user input

## Technologies Used

- Python 3
- JSON
- `datetime` module

## How to Run

1. Install Python 3.
2. Download this repository to your computer.
3. Open a terminal in the project folder.
4. Run the following command:

   `python campuspilot.py`

   On some Windows systems, use `py campuspilot.py`.
